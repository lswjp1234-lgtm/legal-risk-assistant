**Q1：** 在业务往来中，有没有给过政府官员、合作方负责人回扣或好处费？
- A. 没有
- B. 有过人情往来、礼品，但金额很小
- C. 行业有"潜规则"，难以避免
- D. 经常这样做

> *王律师：商业贿赂是刑事犯罪，单位行贿和个人行贿都是。别以为"金额小就没问题"，司法解释里没有"小额豁免"这一条。关键是区分正常人情往来和行贿——金额大、有明确请托事项的，就是行贿。建议：有类似行为的，尽快找律师做一次合规评估，主动整改比被动被抓强。*

**Q2：** 公司的产品宣传材料、销售承诺有没有夸大或无法完全兑现的情况？
- A. 没有，实事求是
- B. 有些承诺偏乐观，但没刻意欺诈
- C. 有过夸大宣传被投诉
- D. 经常用夸大宣传吸引客户

> *王律师：虚假宣传严重了就是合同欺诈，再严重就是诈骗罪。注意"明知有问题还卖"和"事后发现有问题继续卖"在法律上性质不同——后者有主观故意，量刑会加重。建议：本周内把所有宣传材料过一遍，把任何带"最""第一""保证"字眼的全部改掉。*

**Q3：** 公司有没有向员工、客户或社会公众进行过资金募集或借款（不包括正常工资和货款）？
- A. 没有
- B. 有向员工借款，有书面协议，金额不大
- C. 有向客户或朋友筹资过
- D. 正在进行面向公众的集资活动

> *王律师：非法吸收公众存款罪，立案标准很低（金额20万/人数30人/造成损失10万，三选一即够）。老板最容易犯的错是"我是借款不是集资"的侥幸心理。建议：如有向不特定对象筹资，哪怕你真的打算还钱，也先找律师确认性质——这事的代价是自由的代价，不是钱的代价。*

**Q4：** 发票管理是否规范？合同、发票、资金流向是否完全一致？
- A. 严格规范，三流完全一致
- B. 基本规范，偶尔有小差异
- C. 管理比较随意，有不一致的情况
- D. 有买过发票或开过与实际业务不符的发票

> *王律师：虚开增值税专用发票，最高可判无期徒刑，这是没有商量余地的红线。"三流不一致"（合同、发票、资金不匹配）现在金税四期大数据自动比对，一查一个准。如有历史问题，建议尽快主动向税务机关说明——主动说明和被动查出来，处理结果天差地别。*

**Q5：** 核心岗位有没有进行过刑事合规排查？
- A. 有，每年排查
- B. 有，但只是简单了解
- C. 没有排查过
- D. 从没想过这个问题

> *王律师：刑事合规排查不是"查员工"，是查公司制度有没有漏洞。很多老板不知道自己已经在犯罪边缘。建议先从最容易出问题的几个环节自查：采购回扣、虚增成本、资金往来。*

**Q6：** 公司有没有建立刑事合规制度？
- A. 有完整制度，定期培训
- B. 有简单制度
- C. 没有制度
- D. 不清楚什么是刑事合规

> *王律师：刑事合规不是大企业才需要的东西。中小企业一旦出事，老板就是第一责任人。有制度，至少能证明你"不知道"，没有制度，就是"故意"。而且现在检察机关有合规不起诉制度——有合规制度的企业，出事了可以争取从宽处理。*
